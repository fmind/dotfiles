# Upstream Skill Index

This catalog vendors no external skill. Each tool or product skill is a single first-party file that names the official bundle, the command that lists what the current release ships, and the project-scope install command run after reviewing the snapshot per [agent-skills](SKILL.md). Upstream skill names are never copied into the catalog because the sets grow; the `--list` output is the source of truth.

## Host plugin bundles

- `anthropics/skills`: Claude's document and tooling skills, installed through Claude's plugin command only when a task needs one.
- `openai/plugins`: curated Codex plugins that bundle skills; it supersedes `openai/skills`.
- `astral-sh/claude-code-plugins`: Astral's Claude plugins for its Python tools; check the repository is still maintained before installing.

Search for more with `skills find <query>`, `gh skill search <query>`, or [skills.sh](https://skills.sh). Mermaid, D2, Hugo, Typst, mise, dprint, lefthook, OpenTofu, trivy, gitleaks, zizmor, cosign, and `acli` publish no official skill, so their first-party skills stay self-contained. Every user-scope installer (`hf skills add -g`, `skills add -g`, `gh skill install --scope user`) writes to `~/.agents/skills`, which is this catalog: install upstream skills at project scope only.
